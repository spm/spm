# CLA signatures

Storage branch for the CLA Assistant (.github/workflows/cla.yml).
It holds signatures/version1/cla.json and nothing else.

Do not merge this branch into main.

The file records who signed the SPM CLA, when, and the pull request
comment they signed in. Its history continues main's history, so
git log signatures/version1/cla.json shows every signature commit
since the file was created.
